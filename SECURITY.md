# Security

Elsewhere opens project files from shared folders and connects directly to collaborators' computers, so
security problems matter.

## Reporting a problem

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a
vulnerability**. Please don't open a public issue.

Include what you found, how to reproduce it, and the version of Elsewhere (Help > About Elsewhere). You'll get
a reply within a week. Once a fix is released, you're welcome to be credited in the release notes.

## What's in scope

- Elsewhere itself: opening projects and imported sessions (Pro Tools, AAF, DAWproject, Ableton, Cubase),
  collaboration through shared folders, live sessions, and the link with Somewhere.
- Not third-party plug-ins that Elsewhere hosts. Report those to their makers.
