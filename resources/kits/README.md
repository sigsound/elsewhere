# Recorded drum kits

These samples are curated from three free drum libraries by Karoryfer Lecolds, released
under **CC0 1.0 Universal** (public domain): https://shop.karoryfer.com/pages/free-samples

| Elsewhere kit   | From                 |
|--------------|----------------------|
| Big Rusty    | Big Rusty Drums      |
| Brushes      | Big Rusty Drums      |
| Studio Dry   | Unruly Drums         |
| Unruly Room  | Unruly Drums         |
| Seventies    | Gogodze Phu Vol II   |
| Retro Tape   | Gogodze Phu Vol II   |

Thank you, Karoryfer. To rebuild them, download the libraries and run
`scripts/build-recorded-kits.py <folder> resources/kits`.
